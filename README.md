# Assignment 4 - Forms and Validation

## About

This project was created to practice HTML forms, Bootstrap components, HTML5 validation, and simple JavaScript validation.

The project contains three pages:

1. Simple Contact Form
2. Bootstrap Contact Form
3. Registration Form

All pages are connected with a navigation bar.

## Part 1 - Contact Form

The first page is a simple contact form created with HTML and CSS.

It contains:

- Name
- Email
- Message
- Submit button

I used HTML5 validation attributes such as `required`, `minlength`, `maxlength`, and `type="email"`.

## Part 2 - Bootstrap Contact Form

The second page recreates the contact form using Bootstrap.

I used Bootstrap classes such as:

- `container`
- `row`
- `col-12`
- `col-md-6`
- `form-label`
- `form-control`
- `btn`
- `is-valid`
- `is-invalid`
- `valid-feedback`
- `invalid-feedback`

Bootstrap Grid is used to make the form responsive.

## Part 3 - Registration Form

The registration form contains:

- First Name
- Last Name
- Email
- Password
- Confirm Password
- Gender
- Hobbies
- Country
- Submit and Reset buttons

HTML5 validation is used for required fields, email format, and password length.

Bootstrap is used for validation feedback and responsive layout.

A small JavaScript script checks if Password and Confirm Password are the same.

## Validation

HTML5 handles basic validation using:

- `required`
- `type="email"`
- `minlength`
- `maxlength`

Bootstrap shows valid and invalid feedback.

JavaScript is used only for custom validation, such as comparing the two password fields.
